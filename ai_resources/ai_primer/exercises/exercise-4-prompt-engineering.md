# Exercise 4: Stacking Techniques

## Goal
Deliberately combine at least 3 named techniques from `04-prompt-engineering.md` in a single prompt, and confirm the output actually reflects each one.

## Scenario
Pick a coding task from one of our own codebases. This can be literally anything! 

## Steps
1. Before writing anything, pick at least 3 techniques from `04-prompt-engineering.md` (role, constraint-based, Chain-of-Thought, decomposition, output control) that make sense for this task, and write down which ones and why.
2. Write **one** prompt that uses all of them together.
3. Run it, then check the output against each technique: did the role actually change the tone/detail level? Did it obey every constraint? Did it follow your requested output format?
4. If a technique didn't visibly "take," rewrite just that part of the prompt and re-run.

## Self-Check
- [ ] Used at least 3 distinct named techniques in one prompt
- [ ] Identified which techniques I was using *before* running the prompt, not after
- [ ] Verified the output actually reflected each technique, rather than assuming it did

## Reflection
Which technique had the biggest effect on the output for this particular task? Was there one that didn't seem to matter much here?
