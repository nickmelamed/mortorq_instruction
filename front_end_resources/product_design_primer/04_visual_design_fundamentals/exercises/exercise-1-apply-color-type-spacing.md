# Exercise 1: Apply Color, Type, and Spacing With Reasons

## Goal
Make every visual decision on a real screen justifiable in one sentence, instead of defaulting to preference.

## Steps
1. Take the wireframe you produced in `02` (or any wireframe from this primer) and choose 3-4 colors for it — text, background, and at least one meaningful accent (like the alliance red/blue).
2. Check every text/background color pair against a contrast checker and confirm each meets WCAG's 4.5:1 (normal text) or 3:1 (large text) minimum. Adjust any pair that fails.
3. Choose a type scale of 3-4 sizes related by a consistent ratio, and assign them across the screen so the single most important element is unambiguous at a glance.
4. Choose a spacing scale (a short list of values, e.g. multiples of 8px) and apply it consistently to every padding and gap on the screen — no one-off numbers.
5. For each color, type, and spacing choice, write a one-sentence reason. If any sentence just says "it looked good," revisit that choice.

## Self-Check
- [ ] Every text/background color pair passes WCAG contrast minimums, checked with an actual tool, not by eye
- [ ] My type scale has 3-4 sizes total, and the most important element on screen is visually obvious before reading any text
- [ ] My spacing uses only values from a single consistent scale, with no ad hoc numbers
- [ ] Every color, type, and spacing decision has a one-sentence reason that isn't just a preference

## Reflection
Pick one color or type decision you almost made on preference alone before finding a functional reason for it. What was the functional reason, and would you have found it without forcing yourself to write one down?
