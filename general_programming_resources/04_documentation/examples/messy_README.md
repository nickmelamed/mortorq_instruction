shooter config

This project has a class called ShooterConfig.java which has a constant called FLYWHEEL_RPM which is set to 4500 and there is a method computeSpinUpTime which takes accelerationRpmPerSecond as a parameter and divides FLYWHEEL_RPM by it and returns the result, and there's also a method recordShot which increments an internal counter called shotCount by one every time it's called, and shotCount starts at zero and there's a getShotCount method that returns it. If you want to run this you need Java installed, and you compile it with javac ShooterConfig.java in the same folder as the file after cloning the repo which you should have already done to be reading this, and then you run it with java ShooterConfig assuming there's a main method, check the file to see if there's one already added by the time you read this because it might have changed. Also this depends on nothing else outside the standard library so you don't need to install any dependencies for this to work correctly on your machine assuming you have a JDK, and by the way the reason FLYWHEEL_RPM is 4500 specifically is that it's the minimum speed that reliably clears the low goal from anywhere in the shooting zone based on week 3 testing, going lower undershoots long shots and going higher shreds the ball at close range, which is probably useful to know if you ever need to change it.
