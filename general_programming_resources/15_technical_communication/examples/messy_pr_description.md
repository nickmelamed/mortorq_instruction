# PR: intake fix

fixed the intake, it kept stalling. changed some stuff in Intake.java and IntakeConstants.java. basically what happened is we swapped to the new intake wheels a couple weeks ago for this year's game piece and nobody updated the current limit so when a piece got wedged against the frame at a bad angle the motor just kept drawing more and more current trying to push through it instead of backing off, which is also probably why we had that brownout at the last practice match honestly. set the supply current limit to 40A on the intake Talon FX config (it was unset before, which meant no limit at all) and also bumped the jam-detection threshold from 60A to 35A since 60 was tuned for the old wheels and never got revisited. tested by jamming a piece against the frame on purpose on the practice bot and it now backs off within about half a second instead of stalling, also ran a bunch of normal intake cycles afterward at full speed and nothing regressed there. should probably also check this doesn't mess with the auto routine's intake timing but haven't gotten to that yet.
